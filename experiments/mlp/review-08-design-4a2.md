# Review 8: stage 4a.2 design

**Status:** Rejected historical design.

The review examines whether two versions of the event instrument observe the same underlying trajectories consistently, and whether the planned experiment has a meaningful falsification criterion. It rejected the draft and listed prerequisites before freezing a new predictor. This negative decision is retained to explain the transition to deterministic instrumentation and a separate rate pilot.
