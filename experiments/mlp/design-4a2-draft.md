# Stage 4a.2: draft power study

**Status:** Superseded design.

This draft proposed a population study of inactive episodes in MLPs after instrument calibration. It separates intended endpoints, an unfrozen grid, analysis requirements, and design risks. The subsequent adversarial review rejected this design. The later deterministic rate pilot and stage 4a.3 protocol provide the route to the released confirmatory study; this draft must not be used as its execution protocol.
