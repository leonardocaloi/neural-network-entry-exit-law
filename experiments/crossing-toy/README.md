# Crossing toy

**Status:** Archived design.

This minimal polynomial crossing model was used to examine the original contact analogy near a singular set. The design was archived because the proposed mechanism did not yield the intended independent discriminator at the relevant order. It is background for the research question, not evidence for a general contact law.

The [complete original protocol](https://github.com/leonardocaloi/neural-network-entry-exit-law/blob/a331371220b539a467a7302eac8ab580740b5014/05-experimentos/p5-cruz/README.md)
retains its equations, decision rules, and original wording. This English guide
does not change that protocol. Numerical scripts and data remain in this directory
under the [English path mapping](../../docs/provenance/path-map-v0.2.0.tsv).

Start with the [negative-results register](../NEGATIVE-RESULTS.md) and the
[research map](../../docs/RESEARCH-MAP.md) for the relationship to the later
deterministic theorem. Historical scripts may assume execution from their own
directory; supported central reproduction commands are in the
[reproduction guide](../../docs/REPRODUCIBILITY.md).
