# Adam and the residual-memory mechanism

**Status:** Exploratory optimizer study.

This pilot asks whether Adam changes the clock that predicts release from an inactive episode. The historical hypotheses distinguish a signed-area mechanism, an epsilon-dependent transition, and the possibility that no simple first-order law survives. The pilot records deviations from its initial design. Its observations are separate from the gradient-flow theorem and from the MLP and transformer confirmatory campaigns.
