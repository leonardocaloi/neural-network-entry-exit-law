# Adam barrier study: historical protocol

**Status:** Protocol and analysis artifacts; outside the main manuscript claims.

This record develops the H-BARREIRA protocol, including one primary endpoint, epsilon and gradient-descent saturation cases, beta-invariance and second-moment-memory secondary analyses, and a diagnostic decomposition. It records an abandoned acceptance window and the decisions following review 17. The English overview does not redefine any decision threshold or assert that a new campaign has been completed. Consult the original protocol and frozen configurations for the exact rules.
