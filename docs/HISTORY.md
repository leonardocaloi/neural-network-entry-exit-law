# Research history and language policy

Version 0.2.0 provides English directory names, script entry-point filenames,
navigation, and reading guides. The complete Portuguese source records remain
available in the published Git history; the links below pin the exact
pre-reorganization commit. These guides summarize a record's purpose and status;
they are not translations of every proof or a replacement for the frozen protocol.

The current English manuscript contains the principal theorem statements and
proofs. Historical LaTeX drafts, numerical code, and saved data remain in the
checkout. Internal function names, CLI flags, configuration keys, event labels,
and recorded console output are retained where changing them would alter an
existing interface or a frozen scientific record. Some code comments also retain
their original language. A Portuguese machine identifier is not a new endpoint.

The [path mapping](provenance/path-map-v0.2.0.tsv) locates moved artifacts.
The [commit mapping](provenance/commit-map.tsv) relates private-research hashes
to the filtered public history. Neither file rewrites preregistration chronology.
The inclusion list in `provenance/included-paths.txt` describes the original
publication extraction and intentionally retains its historical paths.
