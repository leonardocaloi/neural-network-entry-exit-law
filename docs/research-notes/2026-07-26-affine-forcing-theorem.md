# From two units to an affine live subsystem

**Status:** Development note for manuscript Theorem 6.

This note audits the proof ingredients needed to replace the original live unit by an affine subsystem with a fixed activation pattern. It separates assumptions on residual forcing from width-dependent estimates, feedback control, and entry/release analysis. The complete public statement is in the manuscript. The note is useful for understanding the derivation sequence, not as an independent proof certificate.
