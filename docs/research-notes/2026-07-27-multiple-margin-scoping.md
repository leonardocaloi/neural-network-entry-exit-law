# Multiple active margins: extension scoping

**Status:** Exploratory reduction and open questions.

The note studies data-Gram coupling between margins of one unit, candidate leader-gap conditions, and a vector description when no single datum dominates. It discusses exponential dominance and analogies with tropical geometry and interacting-population equations. Those analogies do not establish equivalence to the full theories. Some replay and scratchpad scripts cited in the original note are not in the release, so its additional numerical observations are not independently reproducible from this repository alone.
