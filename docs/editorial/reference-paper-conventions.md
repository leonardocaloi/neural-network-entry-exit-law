# Writing conventions in reference papers

**Status:** Historical editorial study.

The original note records how selected reference papers organize titles, abstracts, statements, proofs, and limitations. It distinguishes observed conventions from recommendations. It is an editorial aid, not scientific evidence for the entry-exit result and not a statement of current venue requirements.
