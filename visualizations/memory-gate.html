Inactive Units and Residual Memory

An exploratory two-unit simulation with adjustable activation sharpness and noise. This stochastic toy illustrates trajectories; it does not verify the deterministic entry-exit theorem.

The signed area shown uses the current leading datum. With noise, a return can occur without an area-zero event. Start the simulation to explore; pause it before changing settings for a still view.
